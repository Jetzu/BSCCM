**1. Preserve fine spatial and angular detail in a new branch**

**Mechanism.** Keep the full-view/zoom predictor as the reference. Add a small independently trained branch that processes the native LF stack using separate shallow stems for BF/DPC/phase, low-angle DF, and high-angle DF. Preserve a 16×16 or 32×32 spatial grid until late fusion; use small convolutions or local attention and marker-specific spatial pooling. Use GroupNorm in this new branch. The first experiment can predict only the four weak targets, blending with the reference at a source-selected, fixed weight. It is a new spatial/angular representation, rather than another copy of the zoom model or removal of the ResNet maxpool.

**Why this bottleneck.** The hypothesis is that rare-subset evidence survives in local texture, scattering patterns, or cell-edge structure but is weakened by early channel mixing and spatial compression. Keeping DF pathways distinct is especially motivated for CD123: K014 reports DF carrying more CD123 signal than BF/phase, although that evidence is FOV/v4 and must be retested for this GOAL. HLA-DR and CD19/CD56 may require local morphology beyond broad lineage. This can raise the within-draw ceiling rather than only remove draw shift.

**Grounding.** Optical channel identities and usable groups are explicit in [data.py:8](/home/hpc/v181bb/v181bb10/BSCCM/bsccm/data.py:8), including `df_low`, `df_high`, and `dpc4`. The baseline passes all channels through one `timm` encoder, then linear heads ([train_lf.py:61](/home/hpc/v181bb/v181bb10/BSCCM/scripts/train_lf.py:61)). Existing pixel-unshuffle code demonstrates a way to preserve native samples before spatial compression ([fm_common.py:110](/home/hpc/v181bb/v181bb10/BSCCM/scripts/fm_common.py:110)); it is an implementation option, not evidence that it improves markers.

**Expected gain.** Four target lifts of .02–.06 would contribute +.007–.022 before accounting for redundancy with the existing ensemble. Budget +.004–.015 after blending. Expect the upper end only if this branch improves within-source discrimination and supplies new errors, not merely another lineage estimate.

**Cheapest falsifier.** For .8–1.5 H100-h, train a compact branch for 3–5 epochs per source, with identical source FOV partitions and label exposure as its control. Compare angular stems against an equally small early-fusion branch, not just against the much larger ResNet. Reject the proposed representation advantage if it supplies neither roughly +.02 average weak-target r on reserved source FOVs nor useful residual predictions beyond the matched base/zoom model. Freeze the surviving design before scoring the opposite draw. If the short model is clearly underfit, this falsifies the cheap design only.

**Build / constraint touch.** 2–3 days for branch, spatial pooling, and source-only blend selection. Keep real input artefacts and the existing normaliser. Do not claim increased optical resolution, use histology, synthesize a larger field, or repeat the refuted no-maxpool/shared-BN variants. Directional channel identities must remain correct.

**2. Stop forcing weak assays to share the same late representation**

**Mechanism.** Start from the appropriate inductive SSL encoder and fit a shared early trunk, then give CD19, CD56, CD123, and HLA-DR separate late residual blocks and pooling layers. Train each private path only from its observed assay labels. Keep the seven other common targets on the reference outputs. Gate/class losses may update the shared broad-lineage path but should not update the private weak-marker blocks. Test a private last-block implementation first; only expand to independent encoders if it shows benefit.

**Why this bottleneck.** Disjoint single-antibody slides supply most weak-target labels. Their gradients currently meet in one encoder alongside strong lineage markers, autofluorescence, and batch-0-only gated classification. A representation adequate for neutrophil/monocyte separation need not retain B/NK or dim-marker differences. Private late capacity tests task interference directly; it does not just upweight the same tails. Thus it differs from N022, whose tail/focal weighting helped only in distribution.

**Grounding.** Single-antibody masks, the eight single-target names, and class-label availability are defined in [make_targets_v3.py:23](/home/hpc/v181bb/v181bb10/BSCCM/scripts/make_targets_v3.py:23) and [make_targets_v3.py:44](/home/hpc/v181bb/v181bb10/BSCCM/scripts/make_targets_v3.py:44). Classes are from batch-0 `all` cells, not B/NK/basophil annotations on all single-antibody cells. Shared heads and regression-plus-class loss are at [train_lf.py:67](/home/hpc/v181bb/v181bb10/BSCCM/scripts/train_lf.py:67) and [train_lf.py:140](/home/hpc/v181bb/v181bb10/BSCCM/scripts/train_lf.py:140). Never treat missing labels as negatives or assign group fluorescence to individual markers.

**Expected gain.** A .02–.04 average lift on four targets is +.007–.015 in the mean; allow +.003–.012 after ensemble redundancy and incomplete transfer. HLA-DR is the first priority because its D1b draw-1 deficit is .145; CD19 is the complementary low-ceiling test. A large within-source gain with no held-out gain would identify shift/assay noise rather than solve the GOAL.

**Cheapest falsifier.** For .5–1.0 H100-h, fit private HLA-DR and CD19 last blocks in both source directions, compared with a parameter-matched shared extension and a classification-loss-off control. Use the shared source-only baseline, never a supervised checkpoint that has already fitted the validation FOVs. Reject if private capacity does not improve within-source r or if a fixed blend contributes nothing beyond the base/zoom reference on transfer. Inspect within-LF-morphology strata so improved lymphocyte-versus-granulocyte separation cannot masquerade as B/NK resolution.

**Build / constraint touch.** 1–2 days. Extra parameters increase overfitting risk on single slides; use source FOV validation. No new labels, test-draw adaptation, adversary, or fluorescence input is required. The auxiliary gated-loss asymmetry between training draws must be reported.

**3. Replace some SSL invariance with prediction of LF detail**

**Mechanism.** Continue source-only SSL with a small decoder predicting masked LF patches and held-out illumination channels from the visible LF channels. Give extra reconstruction weight to local high-frequency residuals, while retaining some existing global SSL regularisation to avoid a pure low-level copier. Preserve illumination identities in the decoder. Compare with an equal-compute continuation of the existing augmentation SSL. Initially reuse ResNet-50 so architecture and pretraining objective are separable.

**Why this bottleneck.** Current SSL explicitly matches representations despite blur, scale perturbation, noise, and channel dropping. Those invariances may discard exactly the subtle per-cell scattering/texture information needed for CD19/CD56/CD123/HLA-DR, while preserving easy lineage information. Reconstruction asks the encoder to retain predictable angular and spatial detail. It differs from the unsuccessful random cross-illumination *invariance* probe: predicting a missing channel does not require all illumination views to have identical representations.

**Grounding.** [ssl.py:120](/home/hpc/v181bb/v181bb10/BSCCM/bsccm/ssl.py:120) applies geometric resampling, blur up to sigma .8, gain/noise, and channel masks; [ssl.py:88](/home/hpc/v181bb/v181bb10/BSCCM/bsccm/ssl.py:88) penalises view differences. The full LF stack is already accessible through `RawSet` and `GPUNorm`. The SSL script has an excluded-batch switch ([train_ssl_lf.py:159](/home/hpc/v181bb/v181bb10/BSCCM/scripts/train_ssl_lf.py:159)), but that row-selection block has **no `hist_row < 0` filter**. A new harness must explicitly apply the non-Giemsa filter as well as batch exclusion.

**Expected gain.** Retaining enough extra detail for .01–.04 lifts on the four weak targets yields approximately +.004–.015 before redundancy; use +.003–.011 as the ensemble planning range. If labels dominate the ceiling, this will improve reconstruction without improving the GOAL.

**Cheapest falsifier.** Allocate 2.0–3.5 H100-h across both source directions for short continued pretraining plus matched fine-tuning. Compare three prespecified conditions: existing-objective continuation, reconstruction continuation, and unchanged init. Reject if reconstruction improves its own LF loss but not weak-target r after fine-tuning or blend complementarity. Frozen linear probes alone are insufficient: K017 shows that they previously failed to rank useful initialisations. Do not spend a full new 40-epoch pretrain before this screen.

**Build / constraint touch.** 2–3 days. No fluorescence reconstruction, no GS cells, and no held-out-draw images in any SSL objective or early-stopping set. Reconstruction must not turn into a proposal to clean/replace LF inputs. The decoder is discarded; inference still uses the original LF observations.

**4. Train against synthetic instrument variation within the source draw**

**Mechanism.** Keep the current normalisation and actual artefacts at inference. During supervised training, generate two appearances of each source cell using calibrated, label-independent nuisance perturbations: coherent per-illumination-family gains, small offsets/smooth shading fields, modest blur/focus variation, and sensor noise. Fit perturbation ranges using source-only crop borders and source slide variation, without target-draw inspection. Pair ordinary v5 supervision with a small consistency loss between the two predictions. Retain an unperturbed fraction of training examples.

**Why this bottleneck.** This directly attacks the approximately .016 shift component. The present fine-tune learns from only one observed draw appearance with translation augmentation, even though SSL had mild appearance variation. The intervention breaks dependence on technical LF appearance while preserving the physical cell. It could benefit HLA-DR/CD19/CD56 and pooled CD45, where D1b finds larger shift costs. The draw-0 CD123 counterexample means stronger invariance is not automatically beneficial.

**Grounding.** Normalised LF is `log((raw-30)/(background_crop-30)/slide_scale)/s_c` ([gpu_norm.py:24](/home/hpc/v181bb/v181bb10/BSCCM/bsccm/gpu_norm.py:24)). Consequently log-domain offsets correspond to multiplicative intensity variation; additive raw-count offsets should instead be applied consistently before that transform. The supervised hook currently only translates ([train_lf.py:48](/home/hpc/v181bb/v181bb10/BSCCM/scripts/train_lf.py:48)). Do not invent rotations: several directional DF channels have no complete rotated partner, as [data.py:42](/home/hpc/v181bb/v181bb10/BSCCM/bsccm/data.py:42) warns.

**Expected gain.** Recovering 20–50% of the .016 yardstick suggests +.003–.008. This alone probably cannot reach .67. It is more complementary to ideas 1/2 than adding another same-scale ensemble member, although the projection is not a bound.

**Cheapest falsifier.** For .5–.9 H100-h, use one prespecified moderate randomisation strength in both directions against the same-recipe baseline. First verify that it improves performance under held-out synthetic nuisance settings without collapsing source clean weak-target r. After freezing it, score real transfer once. Reject if synthetic robustness improves but opposite-draw weak-target r and pooled CD45 do not, or if clean-source loss of information cancels the transfer gain. Include a gain/noise-only control to establish whether physical grouping adds anything beyond ordinary augmentation.

**Build / constraint touch.** About 1 day. This respects “augment instead of cleaning inputs.” Source metadata can define training groups or augmentation ranges but must not be a predictive input. No test-draw calibration, DANN, AdaBN, per-test-batch normalisation, or target-image consistency training. Preserve phase amplitude unless the perturbation has a justified physical interpretation.

**5. Optimise the evaluated correlation, with stable task-wise statistics**

**Mechanism.** Replace the main regression objective in an otherwise unchanged model with the equal mean of `1 − Pearson(pred, v5_label)` per observed marker, plus a small MSE term that stabilises output scale. Accumulate enough same-target examples across source FOVs to obtain stable moments; compute those moments in float32. Use target-homogeneous batches or gradient accumulation, and compare against MSE using the exact same sampler. Fix the correlation/MSE coefficient before opposite-draw evaluation.

**Why this bottleneck.** Weak-marker labels have assay-dependent scaling, dim tails, and sparse supervision. Finite-capacity optimisation may spend effort fitting their amplitude or noisy examples rather than their covariance with LF evidence. Correlation training can prioritise what this GOAL actually evaluates. **MSE already has a population-optimal conditional-mean solution for Pearson correlation**, so this is an optimisation/regularisation hypothesis, not a way to beat a label-noise ceiling. Expected upside is therefore smaller than for added representations.

**Grounding.** The current objective is per-task masked MSE, averaged over tasks present in a batch ([train_lf.py:140](/home/hpc/v181bb/v181bb10/BSCCM/scripts/train_lf.py:140)); scoring is Pearson ([train_lf.py:84](/home/hpc/v181bb/v181bb10/BSCCM/scripts/train_lf.py:84)). Labels are already asinh-calibrated and z-scored ([make_targets_v3.py:23](/home/hpc/v181bb/v181bb10/BSCCM/scripts/make_targets_v3.py:23)), so simple affine output calibration cannot improve r. Do not sell re-z-scoring, temperature changes, or rank transforms as metric gains without actual predictions and evaluation.

**Expected gain.** Weak-target lifts of .005–.02 imply about +.002–.007 before overlap; plan for +.001–.006 over the ensemble and a high chance of a result inside the ±.004 flat zone. This is cheap enough to test, not the principal route to .67.

**Cheapest falsifier.** For .3–.6 H100-h, run the correlation/MSE comparison on matched source-only FOV partitions in both draws. Reject if the weak-target mean has no consistent advantage or only output variance changes. A coefficient chosen after looking at opposite-draw split-2 r invalidates the screen. Keep original sampling frequencies in the loss or appropriate sampling weights: altered task batching must not silently become tail oversampling, the N022 direction already found unhelpful for transfer.

**Build / constraint touch.** .5–1 day. This changes training loss, not labels, test cohorts, or the metric. Keep missing targets masked. No target-label moment estimation during fitting; source-only output scales are sufficient because r is affine-invariant.

**6. Give LF training denser photon-derived supervision, as targets only**

**Mechanism.** Add small auxiliary outputs predicting source cells' background-corrected fluorescence radial/spectral summaries, alongside the unchanged v5 marker head. Use the existing 6-channel × 4-region integral targets, with source-only label-side calibration and noise weighting. Select the appropriate auxiliary output using assay identity in the *loss*, without giving assay/slide identity to the LF encoder. Start with single-antibody CD123 and HLA-DR. Predict summary structure, not full fluorescence images; discard auxiliary outputs at inference.

**Why this bottleneck.** A single curated scalar can discard spatial evidence and carry unmixing/detrending error. Dense, same-cell target summaries may teach the LF representation to preserve scattering/morphology associated with true fluorescence, while the original marker head remains accountable to the GOAL. N035 finds better within-draw photon-readout agreement for CD123 (.829/.708) and HLA-DR (.880/.649) than CD19 (.322/.558), making the former the rational first targets. CD19/CD56 are conditional extensions, not promised wins. If v5's unpredictable component is the binding ceiling, photon supervision cannot rescue its measured r.

**Grounding.** `fm_prep.npz` provides `integ (N,6,4)`, `noise`, `bg`, `gain`, `stain`, and `stain_names`; `integ` is background-subtracted but **not gain-corrected** ([fm_prep.py:1](/home/hpc/v181bb/v181bb10/BSCCM/scripts/fm_prep.py:1), [fm_prep.py:19](/home/hpc/v181bb/v181bb10/BSCCM/scripts/fm_prep.py:19)). Do not blindly reuse its draw-specific `a_c` or historically fitted gains. Any new calibration must be fitted only on the appropriate source non-GS cells. This is unlike N034/N035 flow matching: no image sampler, distributional surrogate metric, or fluorescence-image readout replaces direct per-cell v5 predictions.

**Expected gain.** Two target lifts of .02–.045 contribute +.004–.008; allow +.002–.008 after blend redundancy. The main failure mode is learning autofluorescence and technical fluorescence appearance without additional marker information. A prettier or better-reconstructed fluorescence target is not evidence of GOAL progress.

**Cheapest falsifier.** For .4–.8 H100-h, add these outputs to the matched source-only model, first for CD123/HLA-DR. Compare true paired targets with auxiliary targets permuted within source assay/FOV, and with the same added output capacity trained only on v5. Reject if auxiliary prediction improves but weak-marker r and residual complementarity do not. If the effect survives only on coarse lineage separation or fluorescence background, stop before expanding to CD19/CD56.

**Build / constraint touch.** 1–2 days. Fluorescence arrays and derived summaries are **label-side supervision only**; they never enter the LF model's input, encoder features, gating features, or inference path. No assay identity input is needed. This touches the fluorescence boundary most directly, so the data-loader/forward interfaces must make that separation explicit. It does not re-unmix the parked batch-1 pooled CD123/HLA-DR/CD14 assay or change benchmark labels.

**A small label audit to choose between these bets**

Before allocating the larger architecture/SSL budget, reserve up to **.2 H100-h** for a source-only label-side audit. Use single-antibody slides and existing raw photon summaries; compare full summaries with independent spatial/spectral views where the dye has adequate signal. Check whether a richer photon readout improves out-of-FOV prediction of the fixed v5 label over the existing ridge result, and whether errors concentrate in dim/censored/background-dominated cells. This is diagnostic GPU work, not a CPU training test.

Spectral channels are not independent repeat measurements: they share autofluorescence, spillover, and calibration. Splitting pixels also introduces spatial heterogeneity and shared-background error. Any split-half estimate needs explicit noise/independence checks on unstained controls and scrutiny of the shared position subtraction. Otherwise it is a **proxy**, not reliability. Neither high split agreement nor low ridge predictability establishes a strict ceiling. Keep the current GOAL unchanged; use the audit to prioritise representation work versus idea 6. No new same-cell acquisition is proposed.
