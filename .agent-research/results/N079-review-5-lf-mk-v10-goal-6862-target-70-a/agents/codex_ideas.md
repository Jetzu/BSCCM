## Common IFC bridge and validation

S-BIAD452: ~98k cells, three donors, nine measured markers/cell (N077/user verification). Audit donor/sample/tube IDs and completeness; partial/unstained tubes cannot supply nine labels. **Only BF1/BF2/SSC enter inference.** Use acquisition compensation, background-subtracted integrated fluorescence, training-donor asinh/scaling. Fluorescence supplies supervision only, including segmentation targets; never fluorescence-derived input masks.

Pixel matching: IFC .25 µm/pixel; BSCCM metadata example .166 ([paper S2](https://arxiv.org/html/2402.06191v1#S2)). Verify release metadata; enlarge IFC by .25/.166≈1.51×, center/pad/crop to 128 (~21.2 µm). Do not shrink by magnification ratio. Match optical bandwidth separately with blur fixed on training/validation donors; compare native IFC resolution. Normalize BF by background transmission and SSC by log1p.

Default **two stems**: IFC three channels; BSCCM 23 LED+phase (SSL-r50 actually consumes 48 with presence planes). Share trunk, retain dataset-specific normalization/affine adapters and assay heads. BF1/BF2 loosely correspond to BSCCM Brightfield; SSC is scatter, not any specific LED darkfield. IFC lacks DPC/phase/angular equivalents. Ablate modality-specific projections into one shared stem with channel/type masks; never replicate SSC into all DF slots.

Map IFC CD14/CD19/CD3/CD45/CD56 to corresponding five BSCCM `single:` targets via shared features and separate assay readouts. Joint test: donor A train, B validation, C untouched test; rotate three prespecified folds. Exclude test donor even from SSL/scaling. Predict all nine simultaneously from BF/SSC; report each marker r, macro/worst r, per-cell standardized vector RMSE and profile cosine, plus five-overlap metrics. BSCCM keeps unchanged GOAL and held-out all-slide pooled metrics; no test-label stacking. Pooled agreement alone cannot validate individual joint decoding.

## Six experiments

**1. Two-stem joint-source r50 — NEW DATA; reverses BSCCM-only training.** Alternate IFC/BSCCM batches, averaging loss by dataset/observed marker. Fully train trunk and assay heads. Adds real joint measurements and ~4,256 B/~3,532 NKT-labelled cells (N077; these are not all pure NK). Expected **+.003–.009**: a hypothetical 50–100% effective data increase gives (.015–.020)×log2(1.5–2)×5/11≈.004–.009; external CD19 .61 versus ours .32–.35 supports headroom, not a transferable ceiling. Cheapest falsifier: donor-held-out IFC pilot plus matched b01 transfer/control, **~2 GPU-h**; stop if IFC predicts CD19 but BSCCM overlap shows no source-validation gain. Build **2 days**. Frozen-probe failure alone cannot reject fine-tuning.

**2. Nine-image fluorescence pretraining — NEW DENSE SUPERVISION.** Train BF/SSC encoder with nine-channel spatial decoder, aligned crops and balanced foreground/background loss; transfer trunk, then fit BSCCM v10 heads. External individual-marker images extend pending N074's six-channel pooled/single BSCCM supervision. Expected **+.002–.008**: +.02 on four outputs would contribute .0073 to the eleven-target mean; N074 supplies no demonstrated gain yet. Cheapest falsifier: coarse 32² decoder versus scalar-only IFC training at matched encoder steps, then b01 transfer/control, **~3 GPU-h**; stop if improved pixels do not improve markers. Build **2–3 days**; reuse N074 alignment logic, not its dataset layout.

**3. Marker-adapted transformer — NEW REPRESENTATION; challenges N053's encoder ranking.** Pretrain DINOv3-S on IFC nine-marker regression using a modality-specific patch embedding; then fine-tune every block on source BSCCM after stem warmup, encoder LR comparable to head LR. N053 already trained all blocks at LR×.1: unfreezing alone is not new. Changes are external marker supervision and physical input adaptation rather than repeated RGB weights. Expected **+0–.008**; failed N053 ViTs and ConvNeXt residual correlations .94–.96 lower confidence. Cheapest falsifier: short external adaptation, matched BSCCM high-LR/×.1 controls, **~4 GPU-h**; stop if neither beats SSL-r50. Build **1–2 days**. N078 separately tests longer in-domain SSL.

**4. Image-conditioned joint uncertainty — NEW JOINT SUPERVISION.** Fit nine means plus rank-2 covariance with marginal MSE and joint Gaussian likelihood on real IFC vectors. No observed marker enters inference; no marker combination is forbidden. Transfer shared features while retaining BSCCM masked scalar heads. Unlike exhausted BSCCM heads, these cells provide measured cross-products. Expected GOAL **+0–.003**; joint likelihood/coverage is the main opportunity because pooled consistency already differs by only .005. Cheapest falsifier: fixed IFC features, diagonal versus rank-2 covariance under donor holdout, **~.3 GPU-h**; stop without held-donor likelihood/coverage gains. Full transfer screen **~2 GPU-h**. Build **1 day**. Report vector RMSE too: better covariance need not improve means.

**5. Distil a 566-angle teacher — NEW MEASUREMENTS; challenges “not image-limited.”** On BSCCM-coherent, synthesize deployed channels with exposure/background correction; teach a paired 24-channel student from all-angle features and pooled labels. Check reconstruction and duplicate cells first. Coherent is **draw 1** ([paper S2](https://arxiv.org/html/2402.06191v1#S2)): permissible only for b1→0, excluded entirely for b0→1. Expected average GOAL **+0–.002**, allowing +.004 in one direction; only 4,304 pooled-labelled cells and N042's low-pass cost ≤.011 make success unlikely. Cheapest falsifier: source-FOV-held-out ridge, all-angle PCA versus synthesized channels, **0 GPU-h**; stop without pooled improvement. Student screen **~1 GPU-h**. Build **2 days**. Teacher improvement must survive distillation.
