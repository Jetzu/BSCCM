## Data corrections and implementation choices

- **C1 is unavailable under the stated label rule.** Direct inspection finds zero single-marker cells with observed autofl in `targets_tt6c.npz`. Its autofl mask covers unstained cells, including GS cells, only. The code emits unavailable C1 rows for every protocol instead of treating placeholder zeros as truth or creating new labels. This does not assert that no raw autofluorescence measurement could be reconstructed elsewhere; that would require a new label/calibration task.
- **The supplied target file does not implement K019's pooled QC mask.** It retains 27,074 failed draw-2 pooled CD123/HLA-DR/CD14 labels. New training and scoring explicitly remove these mask entries, without recalibrating values. A0's own original LF teachers retain their historical training masks for compatibility; the common reference teacher and all scoring use the corrected mask. C2 marks both missing test truth and missing source-draw training truth unavailable for this group. `data_census.json` records the verified counts.
- GS optimization uses only source split 0 and reserves source split 1 for selection: 8,007/994 source train/validation cells for batch1 holdout, 4,495/593 for batch0 holdout. Source split 2 is unused in GS training. TT6c originally trained on the whole source slide, so its training sample count differs. New fits still run exactly 2,500 updates and export their validation-best checkpoint. This implements the requested held-out-FOV selection without exposing the opposite slide.
- New GS image-scale calibration uses source split-0 images only; baseline scaling retains its original `H[:500:5]` rule. The augmentation itself is copied from `train_gs_bind.py`, with production DinoBloom-B/freeze-8 settings. Macenko remains disabled.
- The bridge uses a bounded stochastic interpolant with noise amplitude `sigma*t*(1-t)`, analytic path derivative, zero endpoint noise and deterministic 32-step Euler inference. A2 uses exact minibatch Hungarian OT and explicitly forbids accidental same-cell assignments.
- Completion refits LF projection, marker encoder, both heads and normalization separately for FOV, draw0→draw1 and draw1→draw0. The fixed supplied LF image features themselves come from the specified teachers trained across both draws; the held-out-draw completion claim concerns the newly fitted models, not a source-only image encoder.

## Remaining scientific limits

There is still no GS↔surface-marker truth. M2 products require the stated transitive/CIA assumption; geometry and retrieval cannot establish marker fidelity. C3 is descriptive and cannot verify CD19/CD45 coexpression on singly labelled cells. C1 cannot answer whether a measured single-marker entry improves autofl completion with this target file.

No full-size GPU optimization, CUDA augmentation/backward pass, container dependency check, scheduler signal propagation, or full clinical inference was executable in this sandbox. Smoke metrics test integration and must not be used to rank the arms. Clinical results will be conditional on the one fixed LF-teacher feature pair and seed 0; K025's teacher-run variability still limits stronger clinical claims. Hyperparameter selection is explicitly training-slide autofl r, which need not optimize fine-marker or clinical transfer (K011). All predefined configurations are retained for reporting.
