# N096 red-team review

**Verdict — Hold the “fixed” or “does not fix” conclusion.** The E8 GOAL reproduces. Primary B mixes supervised and unsupervised pairs, and the sandbox pipeline never selects the validation winner required for primary C.

### Findings

1. **Blocker for interpreting B as a test of matching all scored pairs.** `n096_bsccm.py:97,119,126,198`. I enumerated all mask intersections on the actual fit and test rows. In b10, fit has 11 pairs and test has 14. The three extra pairs involve `grp:CD123/HLA-DR/CD14`, with **zero** fit labels and 1,191 test cells. Its linear output stays at initialization. Changes in those three correlations can come entirely from moving its trained partners. In b01 the loss spends 3/14 of its pair weight on pairs absent at test. For b10 E8, all-pair error is .2912 and shared-pair error is .2232. Preserve the registered all-pair endpoint and show the 11 shared pairs and three unsupported pairs separately before attributing a change to matching.

2. **Blocker for primary C.** `n096_sandbox.sbatch:13–19`, `n096_train_ifc_sandbox.py:746`, `n087_sandbox_eval.py:82–97,149–154`. Tracing all 12 invocations shows that every lambda gets test scores, with a separate directory label per donor. Nothing chooses a lambda or compares the selected folds with N080 single on all three donors. History saves only combined validation loss. Ranking that scalar across lambdas penalizes identical predictions more at larger lambda. The printed `pair_corr_abs_err` covers four within-group comparisons. The registered 36-pair result is in the separate `36pairs` table. Specify a common validation criterion, choose within each fold, then apply the registered mean and 3/3 tests. Choosing the best test CSV leaks test labels into selection. A pooled validation choice also reuses each test donor through another fold.

3. **Major — Checkpoint selection changes with the intervention.** `n096_train_ifc_sandbox.py:483–488,498–508,740–746`. N080 selects by validation MSE. N096 adds lambda times the average batch correlation penalty, using contiguous validation batches against one whole-donor target. Reordering identical predictions can change the winning epoch. On archived N080 single donor-2 predictions, I measured squared error over the 36 pairs against that donor’s label matrix. It was .0652 globally, .1012 in packed batches of 256, and .0693 after shuffling. This demonstrates the scoring discrepancy on archived predictions. An arm difference combines the training loss and checkpoint rule. The single treatment also explicitly receives joint validation labels unavailable to the single control.

4. **Major — Autofluorescence alone can improve the headline.** `n096_bsccm.py:16–19,31–36,161–164`. Eight pairs involve autofluorescence, which GOAL excludes. On b01 E8, permuting only that column with `default_rng(0).permutation(len(G))` reduced mean error from .3604 to .2502 with identical marker predictions and GOAL (.686887). Setting it constant gave .1974 because pandas silently dropped eight undefined correlations and averaged the remaining three. Require the expected finite pair count, report autofluorescence accuracy, and interpret the pooled-marker error separately.

5. **Major — The claimed “floor” can be beaten.** `n096_bsccm.py:179–186`. It assumes predictions preserve the source correlation exactly on the test draw. A frozen decoder can change correlation with cell composition. On the same 11 b10 pairs, E8 already scores .2232 below the purported .2637 floor, computed from the actual source fit and test labels. Use it as a source-transfer reference. Its denominator also differs from the 14-pair b10 headline.

6. **Major — B can return no primary result or conceal a direction-specific choice.** `n096_bsccm.py:206–210,225–226`. If every positive lambda misses the .005 tolerance, zero is excluded and every row is unselected. This happened in both directions in `b_summary_quick.csv:2–11`. If different positive lambdas qualify, the printed table still averages by fixed arm. Report eligibility per direction and aggregate the selected rows explicitly. A direction without an eligible intervention cannot supply a measured effect for a selected positive lambda.

7. **Major qualification on validation independence.** `n096_bsccm.py:171–179`, `scripts/train_lf.py:647–651,661,677`. The source split holds out FOVs only after supervised n051 training. Its 27,375 b10 and 12,721 b01 validation rows come from the encoder’s own training rows. The .005 screen can pass a decoder on representations adapted to those labels. Separately, the inherited v10 benchmark chose single-marker cofactors using both draws. The lineage check for CD14/CD16/CD45 even indexes all clean measured splits (`n051_select.py:22–31`). N096’s scores remain comparable to the official fixed benchmark. A claim that the entire label-development pipeline was blind to the held-out draw would be incorrect.

8. **Minor — Two registered descriptive outputs are incomplete.** `n096_bsccm.py:43–50,80–87`. Part A emits E8 and its eight members, omitting the original n051 head. I scored its stored predictions at .686746/.659190. The 500-cell threshold also removes lymphocytes (371) and monocytes (176) from the draw-0 pooled within-type analysis, leaving only granulocytes (544). The output cannot establish a pattern across the three gated types.

9. **Minor — Restart bookkeeping can misidentify artifacts.** `n096_train_ifc_sandbox.py:659–660,671–685,778–785`, `n096_sandbox.sbatch:15–17`. Active weight and source enter the fingerprint, and zero weight preserves the legacy config. A changed-source restart writes a replacement `corr_target.json` before rejecting the incompatible checkpoint. The shell also skips on predictions alone. Interruption after their rename and before metrics publication leaves an apparently finished fold that the evaluator cannot read. Verified by tracing write and guard order.

10. **Minor — Degenerate predictions cause nonfinite gradients or recolouring.** `n096_bsccm.py:107–109,154–157`, `n096_train_ifc_sandbox.py:483–488,722–726`. I passed one constant output column through each implemented correlation loss. Both forward losses were finite, but backpropagation produced nonfinite gradients for that column because the square root is differentiated at zero. The sandbox checks the loss before backward. I also copied the autofluorescence prediction into single:CD45 on the real b10 source predictions. With source correlation exactly one, the residual rescaling returned NaN for all 30 probe predictions. These are tested failure conditions. I found no evidence they occurred in production.

### Controls and scope

I compared both feature dumps against batch IDs and all 15 component prediction files per direction. Source/test row overlap was zero and every component had the official row order. N096 and official `n085_score.py:28–29` agreed on masked common-11 E8 GOAL to floating-point precision (.706573/.686887). Tracing `n096_bsccm.py:175–206` found test labels used for scoring and the transfer reference only. Sandbox donor IDs were disjoint in all folds. Test-label normalization feeds evaluation, while the correlation target indexes validation or training explicitly (`n096_train_ifc_sandbox.py:611–633,657–660,753–759`).

I applied `recolour` to stored n051 predictions using each actual source fit mask, then recomputed every eligible Pearson correlation on its own source rows. Both pooled ZCA and anchored-single transforms reproduced the source targets, with maximum absolute discrepancy below 0.00000009 (`n096_bsccm.py:142–157`). This identity holds on the fit distribution. I did not retrain the full models, exercise cluster preemption, or verify final production effect sizes.
